# LP Insight

First working milestone: private source library and evidence search.

Import Markdown files or a folder. Content is stored in this browser's IndexedDB. Search returns exact excerpts with source filenames, headings, and line numbers. No document contents are sent to an AI provider. Clear library removes local document data.

This is a sample-corpus prototype, not the production system for 16,000 documents. Search is keyword-based; relevance does not establish factual support. AI synthesis, semantic search, shared storage, staff permissions, original-source metadata extraction, and clinical evaluation remain to be implemented.

Next milestone: inspect a representative real corpus; create a versioned ingestion service and database with hybrid retrieval; integrate server-side hosted AI with evidence validation and abstention; then add staff access and shared document administration.
